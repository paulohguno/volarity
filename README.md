# volarity

**Volarity — gestão energética.** Cada recarga tem dono.

MVP do Startup Weekend Chapecó: landing page + protótipo do app que mede a energia de cada carro elétrico no condomínio e cobra de quem carregou.

- `index.html` — landing (estilo apple.com, telas do app em HTML/CSS)
- `painel/` — protótipo navegável do app (morador e síndico), dados simulados

Rodar localmente: `python3 -m http.server 3130` e abrir http://localhost:3130/
